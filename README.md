# Числонавты

«Числонавты» — браузерная математическая игра для детей 7–9 лет. «Космическая десятка» — её первая миссия: ребёнок тренируется находить недостающее слагаемое для чисел от 2 до 10, помогает ракете долететь до планеты и получает визуальную подсказку с клетками для текущей суммы.

## Для кого и какую задачу решает

Игра предназначена для младших школьников, примерно 7–9 лет, которым нужна практика в составе чисел до 10. Она помогает ребёнку самостоятельно потренироваться находить недостающее слагаемое и увидеть состав числа на наглядной модели. Родитель получает отчёт о том, как ребёнок справлялся с заданиями и в каких примерах ошибался, чтобы понять, что стоит повторить. Один игровой сеанс не доказывает полного освоения темы.

## Запуск

Откройте `index.html` в современном браузере. Сборка, установка пакетов и сервер не требуются.

## Сценарий

Игра состоит из приветствия, ввода имени, трёх заданий до практики, шести игровых заданий, трёх новых заданий после практики и итогового экрана со статистикой для родителей. Имя, последний отчёт и число ошибок для каждого примера сохраняются в `localStorage` этого браузера. В следующих занятиях практика чаще выбирает примеры, в которых ребёнок раньше ошибался. Отчёт показывает ошибки за занятие и за всё время; его можно отправить через системное меню браузера. Если Web Share API недоступен, игра предложит скопировать или вручную выделить текст отчёта. Кнопка «Играть ещё» начинает новое занятие.

Все задания проверяют состав числа в пределах десяти, используя два положительных слагаемых. Имя и отчёт остаются в локальном хранилище устройства; отправка отчёта происходит только после нажатия кнопки «Поделиться отчётом».
