# Космическая десятка

Небольшая браузерная математическая игра для детей 7–9 лет. В ней ребёнок тренируется находить недостающее слагаемое для чисел от 2 до 10, помогает ракете долететь до планеты и получает визуальную подсказку с клетками для текущей суммы.

## Запуск

Откройте `index.html` в современном браузере. Сборка, установка пакетов и сервер не требуются.

## Сценарий

Игра состоит из приветствия, трёх заданий до практики, шести игровых заданий, трёх новых заданий после практики и итогового экрана со статистикой для родителей. В каждом занятии задания выбираются из подготовленных наборов с разными целевыми числами от 2 до 10. Результаты существуют только в текущем занятии; кнопка «Играть ещё» начинает занятие заново.

Все задания проверяют состав числа в пределах десяти, используя два положительных слагаемых. Перед тестированием с детьми покажите формулировки и подсказки специалисту по начальному математическому образованию.
